# ShopSmart – Product Catalog Web App

A clean and responsive **Product Catalog** web application built using **HTML, CSS, and JavaScript**.  
It allows users to **browse, search, filter, and purchase products**, with a built-in **cart system and tax calculation**.  
All cart data is saved using **localStorage**, so it remains even after reloading the page.



## Features

-  **Add to Cart** — Add products to your shopping cart easily.  
-  **Search Bar** — Instantly find products by name.  
-  **Category Filter** — Filter products by category (Electronics, Clothing, Books).  
-  **Price Range Filter** — Adjust slider to view products under a set price limit.  
-  **Cart Preview** — Click the cart icon to view added items and total cost.  
-  **Tax Calculation (18%)** — Automatically includes 18% GST in the total.  
-  **LocalStorage Integration** — Cart data is saved even after page reload.  
-  **Checkout Button** — Clears the cart after purchase confirmation.  
-  **Fully Responsive** — Works smoothly on both desktop and mobile devices.

 How It Works
The product list is pre-defined in the JavaScript file (script.js).

Users can:

Search by product name.
Filter by category or maximum price.
Adding a product updates the cart count and total price dynamically.
LocalStorage ensures your cart persists across sessions.
Clicking the 🛒 cart icon toggles the cart view.
The Checkout button resets the cart and shows a thank-you alert.
